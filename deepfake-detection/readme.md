# 🕵️ Deepfake Detection & Forensics Toolkit

A Python-based forensic toolkit designed to detect AI-generated video content. This project specializes in identifying **Deepfake Face Swaps** and **Lip-Sync Manipulations** (like Wav2Lip) using a pipeline of state-of-the-art computer vision models.

The core tool, `detect-evidence.py`, analyzes video frame-by-frame to generate a confidence score and extracts suspicious segments for manual review.

## 🚀 Features  
* **Frame-by-Frame Analysis:** Scans every face in the video using high-precision cropping.  
* **Visual Evidence Generation:** Automatically saves the most suspicious clips (where the AI confidence spikes) for human verification.  
* **Temporal Consistency Check:** Analyzes the video flow to detect hidden cuts or splicing.  
* **Lip-Sync Verification:** (Optional) Checks audio-visual synchronization to spot AI dubbing.

## **🧠 Models Used**

This toolkit combines multiple AI architectures to ensure robust detection. It does not rely on a single metric but cross-references results from the following models:

### **1. Face Detection & Cropping: MTCNN**

* **Model:** Multi-task Cascaded Convolutional Networks (MTCNN)  
* **Library:** facenet-pytorch  
* **Role:** Before analyzing a "fake," we must isolate the face. MTCNN provides high-accuracy face tracking and alignment, ensuring that the background does not interfere with the detection model. It is trained on the **VGGFace2** and **CASIA-WebFace** datasets.

### **2. Deepfake Classification: Vision Transformer (ViT)**

* **Model:** dima806/deepfake_vs_real_image_detection (Hugging Face)  
* **Architecture:** Vision Transformer (ViT-Base, Patch 16)  
* **Role:** This is the "Judge." It splits the cropped face into 16x16 pixel patches and analyzes the noise patterns using a Transformer architecture.  
* **Training Data:** Fine-tuned on **FaceForensics++**, a massive dataset containing real videos and fakes generated by Deepfakes, Face2Face, FaceSwap, and NeuralTextures.

## **🛠️ Usage**

### **Running the Evidence Detector**

The main script processes a video file and outputs a "Fake Score" (0% to 100%).

Bash

python detect-evidence.py --input path/to/video.mp4

### **Output Interpretation**

The script will generate a report in the terminal and save evidence clips:

* **Score < 40%:** Likely Real.  
* **Score > 70%:** Highly Suspicious.  
* **VISUAL_EVIDENCE_X.mp4:** The script extracts the specific seconds where the model detected glitches (blurring around the mouth, inconsistent noise) so you can review them manually.
